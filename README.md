# rpg-stat-generator
A Python RPG stat visualizer that turns attribute values into text-based character stat bars for Strength, Intelligence, and Charisma.

# Stat Forge

A small Python project where I experiment with RPG-style character stats. Enter values for Strength, Intelligence, and Charisma, and the program generates a simple terminal-based character sheet with visual stat bars.

## Logic

- Enter a character name
- Choose values for Strength, Intelligence, and Charisma
- See the stats displayed as RPG-style bars
- Runs in the terminal

## Technology
Python 3
